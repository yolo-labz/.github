# The mark

The org's mark is the gremlin. The monogram and the gremlin are being merged into one head mark by the 2D artist
(`NX-BRAND-MARK`). Until `NX-BRAND-MARK/DECISION.md` lands, this page holds only what already holds.

**Rules**
- One mark per surface at a size: the head mark below 64px, the full figure above.
- The gremlin's mauve is `role.mark`. It does not move into UI chrome.
- The art comes from `profile/assets/brand/`. Nothing is redrawn in a site's own code.
- Say nothing about how an image was made: no caption, alt text, file name or metadata about the method.
- Clear space and minimum size come from the decision file, not from this page. They are added here when it exists.

**Right:** `<img src="/brand/gremlin-hero-gpt-804x770.webp" width="804" height="770" alt="The yolo-labz gremlin at its keyboard">`.
**Wrong:** the same art with a filter, a glow or a new pose. Or alt text that explains the tool that drew it.
